확인된 레퍼런스 신규 제안

REFERENCE MODEL

필드는 자동 진행의 목적지 조정자였다

레퍼런스에서 필드의 주 기능은 전투가 아니라 상점·던전·성 가운데 다음 생산 활동을 정하는 것이다.

확인된 레퍼런스실제 목표 우선순위

열등 장비가 있으면 상점 → 예약된 성 → 현재 지역 미정복 던전 → 열린 지역의 미정복 던전 → 재감염 던전 순으로 목적지를 잡는다. 성은 지역 던전 완료, 요구 적 단계, 공격 예약을 함께 검사한다.

01지역 던전마지막 층 완료
→
02성 준비요구 적 단계 결정
→
03성 정복보스 검문소
→
04이웃 지역상하좌우 잠금 해제
강점

로컬 완료가 월드 진행이 된다

방과 던전에서 얻은 성장이 성이라는 검문소에 모이고, 성 정복이 새 영토를 연다. 작은 자동 행동이 장기 목표와 직접 연결된다.

단절

성 공격 예약이 자동 순환을 끊는다

자동 성 공격 클래스는 존재하지만 기본 자동화 갱신 경로에는 연결되지 않았다. 새 게임은 보스 자동 예약을 기본 정책으로 포함해야 한다.

SITE LIFECYCLE 신규 제안

한 장소가 탐험·거점·방어 콘텐츠로 순환한다

정복 여부와 현재 위협 상태를 분리한다. 이미 얻은 핵심 해금은 되돌리지 않고, 같은 장소의 현재 역할만 바뀐다.

01HIDDEN지도에 존재하지 않음
02RUMORED대략적 위치와 테마만 공개
03DISCOVERED진입 가능 · 위험 일부 확인
04ACTIVE던전 seed와 위협 활성
05CLEARED최초 목표 완료
06OCCUPIED시설 용도 선택
07THREATENED생산·안전 보너스 일시 저하
08DEFENDED방어 후 정상화 · 추가 보상
원칙반격은 벌점이 아니라 새 기회다

위협 상태는 핵심 월드 해금을 취소하지 않는다. 생산 효율 저하, 변형 던전, 방어 보상으로 표현해 “방치했더니 과거 성과가 사라졌다”는 감정을 막는다.

CLEARED → OCCUPIED

완료한 던전은 다음 원정의 기반이 된다

레퍼런스의 농장 전환 아이디어를 확장하되, 던전을 영구히 탐험 후보에서 제거하지 않는다. 시설 용도는 비용과 전환 시간을 지불하고 바꿀 수 있다.

시설주 효과다음 원정에 미치는 영향상충 선택
정찰소인접 노드와 방·보스 정보 공개목표 점수의 불확실성과 실패 위험 감소직접 경제 생산이 낮음
훈련소대기 영웅 XP·역할 숙련로스터의 최저 전투력을 보정주력 파티 즉시 보상은 적음
채굴소골드·제작 재료 생산장비·시설 투자 속도 상승위협 억제에 기여하지 않음
수호소지역 위협 지연·도로 안전도 상승장기 방치와 오프라인 안정성 확보성장 재료 생산이 낮음
확인

정복과 재감염은 별개

레퍼런스의 정복 기록은 유지되고 던전만 다시 감염된다. 최초 완료는 해금, 재감염은 반복 파밍이라는 역할 분리가 유효하다.

제안

EXPLORE ↔ OUTPOST 전환

탐험 모드에서는 희귀 장비·특수 자원을, 거점 모드에서는 패시브 생산을 얻는다. 짧은 쿨다운과 비용으로 되돌릴 수 있어 공간을 잃지 않는다.

FIELD DIRECTOR

거리 대신 목적과 위험을 함께 계산한다

목표 선택은 자동이지만 이유는 숨기지 않는다. 점수의 상위 세 항목을 “새 지역 진행 +100 · 필요한 제작 재료 +28 · 이동 2분 −16”처럼 보여 준다.

fieldUtility =
  진행 가치
+ 필요한 자원 가치
+ 기한·위협 긴급도
+ 현재 빌드 적합도
− 이동 비용
− 예상 실패 위험
− 최근 반복 패널티
우선순위목표 종류선택 조건
1긴급 귀환전멸 위험, 진행을 막는 상태, 복구 실패
2사용자 고정 목표잠금·도달·생존 조건을 만족
3지역 보스·핵심 목표준비도와 안전 정책을 통과
4필수 미완료 던전현재 지역의 진행 게이트와 연결
5위협받는 핵심 시설방어 가치가 원정 기회비용보다 큼
6선택 던전보상·빌드 적합도·신선도 합산
7반복 파밍필요 자원과 변이가 현재 계획에 적합
8안전 거점유효한 공격 목표가 없거나 회복 필요

사용자는 숫자를 직접 편집하기보다 진척 우선·안전·장비 파밍·변이 사냥 같은 프리셋과 소수 슬라이더를 선택한다.

WORLD GRAPH

지형은 장식이 아니라 이동 비용과 사건의 규칙이다

NODE

장소

던전, 성채, 시설, 사건, 휴식 지점이 안정 ID와 상태를 가진다.

EDGE

도로

이동 시간, 위험, 사건 확률, 잠금 조건과 지역 특성을 가진다.

ANCHOR

복귀점

던전 진입 시 node ID와 도착 지점을 저장하고 종료 후 같은 곳으로 돌아온다.

01목표 선택효용 점수와 정책
→
02A* 경로노드·도로 그래프
→
03여정 사건위협은 인터럽트
→
04도착·진입반환 anchor 저장
구현 경계필드 경로와 던전 경로를 분리한다

필드는 지역 노드·도로 A*, 던전은 방 그래프와 지역 waypoint를 사용한다. 여정 사건이 발생해도 최종 목적지는 보존하며, 사건 종료 후 기존 계획을 재평가한다.

REGION BOSS

모든 던전 강제 대신 여러 준비 경로를 허용한다

한 지역은 일반 던전 3~5개, 특수 던전 1개, 지역 보스 1개를 기본 단위로 삼는다. 필수 목표 일부와 영향력, 단서를 조합해 보스를 연다.

필수 목표 3개 중 2개

핵심 진행은 보장하면서 공략 순서를 선택하게 한다.

지역 영향력 목표

던전·사건·시설 성과가 보스 준비에 합류한다.

보스 단서 1개 이상

보스의 기믹 또는 약점을 미리 알아낼 수 있다.

남은 던전은 선택 보상

추가 시설 슬롯, 희귀 보상, 보스 약화로 가치가 남는다.

자동 공격 정책준비 완료와 실제 출격을 끊지 않는다

예상 승률, 회복 자원, 최근 실패, 오프라인 허용 여부를 검사해 성 공격을 자동 예약한다. 실행하지 못하면 “예상 승률 62%가 설정 기준 75%보다 낮음”처럼 한 줄로 설명한다.

4X × ROGUELIKE CADENCE 신규 제안

월드는 넓어지고, 원정은 계속 달라진다

같은 자동 전투 화면에 오래 머물지 않는다. 작은 변화라도 새 정보와 다음 판단을 만들도록, 4X의 누적되는 영토 변화와 로그라이크의 원정별 조합 변화를 서로 다른 시간 간격으로 계속 노출한다.

4X · 누적되는 지도 미지 공개 → 정찰 → 정복 → 거점 → 위협 반격

던전 완료는 신규 노드, 시설, 생산망, 안전한 도로와 적의 대응을 바꾼다. 이전 원정의 결과가 다음 화면에 남는다.

ROGUELIKE · 달라지는 원정 새 seed → 다른 목표 → 방 역할 → 사건·변이 → 빌드 적응

같은 장소를 다시 찾아도 경로 구조, 전투 조합, 위험 규칙과 보상 테마가 달라져 새로운 판단을 요구한다.

20–60초장면적 역할 · 방 목적 · 전리품
2–5분층경로 분기 · 사건 · 회복
8–20분던전목표 · 변이 · 거점 선택
45분+월드영토 · 시설망 · 세력 반응
판정 원칙색만 바꾼 화면은 새로움으로 세지 않는다

지역 테마, 던전 목표, 경로 topology, 변이, 사건, 보상 테마, 거점·위협 상태 가운데 하나 이상이 새 정보나 다른 판단을 만들 때만 변주로 기록한다.
