Miniwar — WinWar II 3.0 원작복각

1995년 Silicon Commander Games의 턴제 전략 게임 WinWar II 3.0을, 원작 리소스를 참고 자료로만 사용해 Godot 4.7로 새로 구현한 복각 프로젝트입니다. 원작의 규칙·화면·조작감을 충실히 재현하면서, 현대 환경에 맞게 다듬습니다.

개요 원작 비교 복각 내용 국가·시스템 전투 규칙 설정·조작 버전 현황

01프로젝트 개요

무엇을, 왜, 어떻게 만들고 있는가

정체

WinWar II 3.0(1995) 복각형 턴제 보드 전략. 7개국이 승점 도달을 두고 육·해·공 전쟁을 벌입니다.

엔진

Godot 4.7 (GL Compatibility). 네이티브 픽셀 렌더로 원작 30px 아이콘을 쨍하게 표시.

방침

원작 타이틀명·OST·리소스 미사용. 시스템은 신규 구현, 원작은 동작·시각 참고로만.

원작 자료 확보

원작 winwar2.exe의 Delphi TPF0 리소스를 파싱해 지역 114개(육지+해역)의 이름·인접·가치·건물·초기 배치, 대륙 비트맵, 아이콘, 사운드 9종, 이벤트 26종의 원문 텍스트를 추출했습니다. 이 데이터를 기준으로 클린룸 재구현합니다.

03복각 내용

무엇을 되살렸는가

맵 · 지형

지역별 사각형 프레임을 원작처럼 4면 입체 베벨(육지=흰/검, 바다=하늘색/검)로. 대륙 랜드마스크 + 지역 박스(소유색 타이틀·가치 배지·유닛/건물 아이콘 그리드).

UI

Win95풍 타이틀바·툴바·상태바, 원작 30px 아이콘 1:1, 3종 보고화면(New Turn Events·Production·AI 완료 팝업) 복각.

사운드

blast(피격)·conquer(점령)·aafire(대공)·bomb(폭격)·bombard(함포)·explosio(원폭)·ding(알림)·drum(턴)·goodmov(이동) 이식. 전투 중 배경음 루프.

음악(BGM)

원작 fingal.mid(멘델스존 핑갈의 동굴)를 렌더링 + 퍼블릭도메인 클래식(Ode to Joy·Pachelbel·Greensleeves)으로 연속 플레이리스트.

이벤트 · 역사

26개 역사 이벤트의 발생문구·사진 캡션·역사 해설 원문 추출. Wikimedia/IWM 퍼블릭도메인 사진을 이벤트별로 배선.

조작

클릭=지역 선택, 드래그=화면 이동, 가장자리 스크롤, 미니맵 클릭 이동, 십자 조준 커서.

04국가 · 시스템

7개국, 9유닛, 자원 = 수입 = 승점

진영

추축 · 독일이탈리아일본 연합 · 미국영국소련프랑스

유닛 9종

  • 육군 — 보병(inf), 기갑(arm)
  • 공군 — 전투기(ftr), 폭격기(bmr)
  • 해군 — 수송선(tr), 항공모함(cv), 구축함(dd), 잠수함(sub), 전함(bb)

건물 3종

  • 공장(생산능력) · 비행장(항공 수용) · 대공포(AA)

경제 · 턴

  • 지역 가치 = 매턴 수입 = 승점 기여
  • 공장에서 유닛 생산(차턴 활성화), 항구→해역 배치
  • 미국 40%·소련 60% 참전 전 자원 제한 → 피침 시 완전 활성화
  • 프랑스 본토 함락 시 비시 프랑스 수립 선택(자원 이전 vs 점수 페널티)

승리

  • 승점 도달 → Free-For-All → 최종 패권

05전투 규칙

원작 d100 계산 유지 + 원작식 다단계 교전

기본 판정

유닛별 공격/방어 수치(atk/def)로 d100 판정. 공·수 동시 사격, 명중 시 대상 1기 제거.

25% 중간종료

한 방씩 번갈아 처리해 공격측 누적손실이 25%에 닿는 즉시 정지(대공포 격추 포함). 방어측 생존 시 일시정지 → 재클릭으로 다음 단계. 원작의 다단계 전투 재현.

병종 상성

대공포(AA) 대공사격, 육군의 대공기 명중 반감, 함선의 잠수함 명중 반감, 잠수함 선제타격(해전).

특수 공격

상륙작전(전멸까지 결전), 함포사격, 전략폭격(공장→비행장→가치), 원자폭탄(생산력 영구 피해), 카미카제.

종료 조건 3가지

  • ① 방어 전멸 → 지역 점령
  • ② 공격 전멸 → 실패
  • ③ 공격측 손실 25% 도달 → 중단(재공격 가능)

전투 후 결과창(양측 국기 + 유닛별 시작/손실/잔존) → 대공포 손실 → 이벤트창 순서로 표시.
