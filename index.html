Project Definition

조작보다 판단이 중요한 방치형 파티 RPG

기본 자동화는 편의 기능이 아니라 장르의 핵심입니다. 플레이어는 공격 버튼을 반복하는 대신 위험 성향, 회복 기준, 전리품 규칙, 성장 우선순위를 설계하고 결과를 관찰합니다.

한 문장 정의 플레이어가 원정대의 빌드와 탐험 원칙을 설계하면, 파티가 살아 있는 월드를 스스로 탐색·정복하고 그 결과로 다음 전략 선택지가 열리는 방치형 파티 RPG.

Core Validation

먼저 증명해야 할 네 가지

콘텐츠 수량보다 자동 순환의 신뢰성을 먼저 검증합니다. 아래 목표가 충족된 뒤 클래스, 지역, 장비와 이벤트를 확장합니다.

Dungeon Seeds 10,000

모든 유효 던전이 완료 또는 설명 가능한 실패 상태에 도달

Unattended Run 8시간

수금·예약·길찾기 대기로 멈추지 않는 무인 콘텐츠 순환

Lost / Duplicate 0건

중복 정산, 리더 단독 전환, 보상 없는 아이템 소실 방지

Determinism 100%

동일 seed·입력·tick에서 목표와 명령 로그가 동일

Core Loop

결정이 자동 행동을 만들고, 자동 행동이 월드를 바꾼다

초단기 전투부터 지역 정복과 계승까지 서로 끊기지 않는 여덟 단계의 순환입니다.

01정책·빌드 설정위험, 회복, 수집, 성장 원칙
02필드 목표 선정위협도와 보상에 따라 자동 결정
03던전 자동 탐색전투, 문, 분기, 계단 처리
04전투·정산XP, 골드, 장비, 유물 조각
05거점 전환정찰·훈련·채굴·수호 시설
06지역 보스탐험·경제·전투 게이트 돌파
07새 지역 해금인접 지역과 새 변형 규칙 개방
08계승·심층 진행수평 해금 뒤 새 원정 시작

Design Pillars

모든 시스템을 판단하는 여섯 기준

01

자율성

전투와 이동은 처음부터 자동이며 반복 조작을 요구하지 않습니다.

02

설명 가능성

현재 행동, 목표, 정지 이유와 실패 원인을 한눈에 보여 줍니다.

03

간접 통제

세부 명령보다 위험 성향과 우선순위 같은 정책으로 개입합니다.

04

월드 변화

던전 완료가 지도, 시설, 생산과 적의 반응을 영구적으로 바꿉니다.

05

다층 완주

방, 층, 던전, 지역과 한 런마다 분명한 완료 보상이 있습니다.

06

유한 복구

자동 시스템은 실패하더라도 정체 감지와 복구를 거쳐 반드시 끝납니다.
